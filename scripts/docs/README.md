# Documentation Scripts

Run these scripts from the repo root through npm:

| npm script | Script | Output |
| --- | --- | --- |
| `npm run docs:legal` | `scripts/docs/build-service-agreement-packet.mjs` | `docs/legal/dist/` |
| `npm run docs:sales:playbook` | `scripts/docs/render-sales-playbook-pdf.mjs` | `docs/sales/dist/Summit-AI-Services-Sales-Playbook.pdf` |
| `npm run docs:sales:leavebehind` | `scripts/docs/render-office-leave-behind-pdf.mjs` | `docs/sales/dist/Summit-AI-Services-Office-Dropoff-Packet.pdf` |
