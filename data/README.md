# Local Runtime Data

This directory is for local/demo runtime state.

| Path | Purpose |
| --- | --- |
| `dentalai.db` | SQLite database created by Prisma seed/start commands. |
| `demo-feedback.db` | Alternate local demo database used by prior feedback workflows. |
| `demo-requests.json` | Local demo request submissions. |
| `uploads/` | Uploaded/imported files used by inventory import workflows. |

Database files and request JSON are local runtime state. Uploaded sample assets may be tracked when they are needed for demos.
