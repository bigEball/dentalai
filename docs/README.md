# Documentation

This directory is organized by audience and purpose.

## Start Here

| Area | Purpose |
| --- | --- |
| [Legal and compliance](legal/README.md) | Legal research, editable templates, and generated contract packets. |
| [Sales enablement](sales/README.md) | Internal playbooks, office collateral, and generated PDFs. |

## Conventions

- Source Markdown lives in named document-set folders, usually as `source.md` for sales collateral or as numbered files for legal template packets.
- Generated files live in `dist/` folders near their source material.
- Document build scripts live in `scripts/docs/`.
- Legal templates are drafts for attorney review and should not be treated as ready-to-sign contracts.
- Keep filenames lowercase and hyphenated unless preserving an externally shared generated asset name.
